# 내 시간의 가격

월급을 넣으면 커피·치킨·아이폰·서울 아파트가 내 노동으로 몇 분·며칠·몇 년인지 보여주는 페이지. 주판(ZOOPAN) 자매품.

- 페이지: `index.html` (빌드 없음, 파일 하나)
- 가격표: `prices.json`
- 갱신: `node update-prices.mjs`
  - 자동: 서울 아파트 평균 매매가(KB 주간), 서울 짜장면 평균(참가격 월간)
  - 수동: 나머지 항목. 공식 가격이 바뀌면 `prices.json`을 고치고 `checked` 날짜를 올린다. 90일 넘으면 스크립트가 경고한다.
- GitHub Actions가 매일 KST 10:00에 갱신하고, 새 데이터가 있을 때만 커밋한다.

시급 = 월급 ÷ 209시간(법정 월 소정근로시간, 주휴 포함). 2026년 최저시급 10,320원.
