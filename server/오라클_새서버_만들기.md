# 내시간역 실시간 서버 — 오라클 새 서버 만들기 (약 5분)

서버가 처음 켜질 때 `cloud-init.yaml`이 Node·Caddy 설치, 승강장 서버 등록, 방화벽, https 인증서까지 알아서 한다. 대표님은 아래 순서대로 만들기만 하면 된다.

## 1. 서버 만들기
1. https://cloud.oracle.com 로그인 → 왼쪽 메뉴 **Compute → Instances → Create instance**
2. **Name**: `time-price-station`
3. **Image**: `Change image` → **Canonical Ubuntu 24.04** (꼭 24.04. 22.04는 Node가 너무 옛날 버전)
4. **Shape**: `Change shape` → **Ampere → VM.Standard.A1.Flex**, OCPU 1 · 메모리 6GB (Always Free 표시 확인)
   - "Out of capacity"가 뜨면 **AMD → VM.Standard.E2.1.Micro**로 바꾼다 (이것도 무료)
5. **Networking**: 기본값 그대로, **Assign a public IPv4 address = 예**
6. **Add SSH keys**: `Paste public keys` 선택 → 아래 한 줄 붙여 넣기
   ```
   ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIAYLMJbjouYqSobR/yGWXSnyliRior5eSSsGM0OXZETS time-price-station
   ```
7. 아래쪽 **Show advanced options → Management → Initialization script → Choose cloud-init script file**
   → `C:\Users\김시현\time-price\server\cloud-init.yaml` 선택 (또는 Paste로 내용 붙여 넣기)
8. **Create**

## 2. 포트 80·443 열기 (오라클 바깥 방화벽)
1. 만든 서버 화면 → **Primary VNIC의 Subnet** 링크 클릭 → **Security Lists** → `Default Security List…` 클릭
2. **Add Ingress Rules** → 두 줄 추가
   | Source CIDR | IP Protocol | Destination Port |
   |---|---|---|
   | 0.0.0.0/0 | TCP | 80 |
   | 0.0.0.0/0 | TCP | 443 |
3. **Add Ingress Rules** 저장

## 3. Claude에게 알려 주기
서버 화면의 **Public IP address**(예: `152.70.xx.xx`)를 알려 주면, Claude가 바깥에서 `https://<IP를 -로 이은 것>.sslip.io/health`로 동작을 확인하고 승강장 공개판에 연결한다. 설치는 서버가 켜진 뒤 3~5분 걸린다.
